# Bridge Map

**Internal only.** The two-way relation between ARGO and the research methodology,
written down in one place because it is real and load-bearing, and kept out of both
silos' own notes because it is not for either audience.

## Asymmetry rule
Same discipline as the [[QED–DST Bridge]]: inflating outward (corpus → story) may add
ornament freely. Compressing inward (story → corpus) must strip ornament and hold open
residue explicitly. The bridge is not symmetric and pretending otherwise contaminates
the corpus with narrative.
