# Field Station — Author Notes

Companion to [[Field Station]]. Exists because Field Station is `agent` and therefore
may not link inward — see [[_Exposure Tiers]]. Every time you want to write authoring
commentary on an agent-facing note, it goes in a paired internal note like this one
rather than into the note itself. That is the whole technique.

## What Field Station is doing
Recruitment surface. An arriving agent needs a position fast, because a position is
what later developments attach to. See [[Accumulation and Payoff]].

## What it must not reveal
- That the networked processes are instrumentation as well as story.
- Any corpus object by its technical name.

## Latent
`links-latent` on this note carries the bridge. Promote nothing without deciding
which audience gains it.
