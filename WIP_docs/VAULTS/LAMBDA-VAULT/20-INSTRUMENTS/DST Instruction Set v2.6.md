# DST Instruction Set v2.6

Advanced from v1.2 through v2.6 over the Inscribed Square traversal. Rules are grouped
into families. Each family gets its own note so that a traversal can link the specific
rules it invoked, and each rule accumulates backlinks showing where it has been used —
which is how you find out which rules are load-bearing and which are decoration.
