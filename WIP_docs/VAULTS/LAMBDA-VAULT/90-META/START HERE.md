# START HERE

You are not fluent in Obsidian yet. This note is the whole manual. Read it once.

## The only three things you must know

1. **A vault is a folder.** Every note is a plain `.md` text file on your disk. Nothing
   is locked in. Delete Obsidian tomorrow and you still have all of this.
2. **Double square brackets make a link.** Type two `[` and Obsidian autocompletes note
   names. A link is two-way automatically — the target note shows a **Backlinks**
   panel listing everything that points at it. You never maintain the reverse direction.
3. **The block at the top between `---` lines is properties (frontmatter).** It is
   searchable, filterable structured data. This is the machinery that keeps your silos
   apart. See [[_Exposure Tiers]].

## First five minutes

- `Ctrl+O` — quick switcher, jump to any note by typing part of its name.
- `Ctrl+Shift+F` — search the whole vault.
- `Ctrl+G` — global graph. `Ctrl+P` then "local graph" for one note's neighborhood.
- `Ctrl+P` — command palette. Everything lives here.
- `Ctrl+E` — toggle edit / reading view.
