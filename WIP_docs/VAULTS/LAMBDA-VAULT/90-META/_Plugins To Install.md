# Plugins To Install

Settings → Community plugins → Browse. Install three. Then stop, or you will spend a
week configuring instead of writing.

1. **Dataview** — turns frontmatter into live queries. Without it, `exposure` and
   `tier` are just labels; with it they are a database. [[_Author Dashboard]] needs it.
2. **Templater** — new notes come out with the frontmatter already correct. Removes the
   main way this schema decays.
3. **Git** — commits the vault folder on a timer. Your corpus is text; version it.
   You already run repos, so this is free.

Deliberately not recommending yet: Excalidraw, Canvas plugins, anything with "AI" in
the name, and the fifty themes. Obsidian ships a native **Canvas** (spatial board of
note cards) and native database-style **table views** — try those before installing
replacements. There is one canvas already in the vault: [[Bridge Map.canvas]].

Core plugins worth switching on immediately: **Backlinks**, **Outgoing links**,
**Tag pane**, **Templates**, **Graph view**, **Properties view**.
